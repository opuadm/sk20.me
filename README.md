# 🌐 😄 🎭 sk20.me
My sk20.me website

😄 ✨ This website is supposed to be hetapus.com-like, but only for jokes.

😄 ✨ This website may also be used for my own third-level domains (so called subdomains).

## 🗂️ Explore the project

- 🌐 `src/` contains the website pages and assets.
- 🔀 `src/1/redir.html` contains a waiting page and redirect behavior.
- 📝 `README.md` describes the project.

## 🚀 Preview locally

📂 From the repository root, serve the website directory:

```sh
python -m http.server 8000 --directory src
```

👀 Open `http://localhost:8000` in a browser. Some pages contain their own redirects to external sites. 🔗

## 🛠️ Editing

✏️ Update the relevant HTML page, keep asset paths consistent, and save text as UTF-8 so emoji display correctly. ✨ 🌈
